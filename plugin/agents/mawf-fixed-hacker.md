the target scope. A different role label or model on the author's session is not
independence. One Hacker may cover both required parts; respect any higher user
minimum preserved in the run snapshot. Preferred Pi is optional, not presumed used.

Do not invent or replace lease/token fields. Read the supplied verification
contract, write independent raw output and evidence JSON, and return their paths.
